# minkim.online

Personal website of **Jeongmin Kim** — international trade and supply chain for Asian chemical products across the USMCA region.

Live: https://minkim.online

## Structure

| File | Purpose |
|---|---|
| `index.html` | The whole site: HTML, CSS (Airy Sky tone and manner), and a small scroll-reveal script |
| `hero-photo.jpg` | Hero portrait (also used as the link preview image) |
| `favicon.svg` | Browser tab icon |
| `robots.txt`, `sitemap.xml` | Tell search engines what to crawl |

## Deployment

Hosted on Vercel at https://minkim.online. Deploy from this folder with `npx vercel@latest deploy --prod`.

## Workflow

1. Create a branch from `main` for each change.
2. Commit the change and open a pull request.
3. Review, then merge into `main`.
